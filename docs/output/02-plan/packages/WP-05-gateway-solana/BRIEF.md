## 1. Objective (2–4 sentences)
Implement `packages/gateway-solana` (module id `gateway_solana`) as a real Open Mercato payment gateway provider using the
existing `payment_gateways` adapter contract (`GatewayAdapter`: `createSession/capture/refund/cancel/getStatus/verifyWebhook/mapStatus`),
modelled on `packages/gateway-stripe`. Payments are **Solana Pay transaction requests** (`solana-payments-q_and_a.md` Q-PAY-01):
the server builds the exact USDC-dev (or SOL) transfer to the tenant treasury with a `reference` key and a memo, and a single
idempotent `reconcile(reference)` marks the request paid from either the Helius event path or polling. The order in Open Mercato
shows the on-chain proof.

## 2. Acceptance criteria covered (from 01-intake/PROBLEM.md)
- **AC-3**: `createSession(order)` returns `{ url, qrPayload, reference, amount, mint, expiresAt }` where `url` is
  `solana:https://<PUBLIC_BASE_URL>/api/gateway_solana/transaction-request/<reference>`; `GET` on that route returns
  `{ label, icon }`; `POST { account }` returns `{ transaction: <base64>, message }` with a transaction that transfers the exact
  amount (`TransferChecked`), carries the memo `aegis:v1:pay:<requestId>` and includes the `reference` pubkey as a read-only key.
- **AC-4**: `reconcile(reference)` marks a request `confirmed` exactly once for a valid transfer and never for under-payment
  (→ `partially_paid`), wrong mint, wrong recipient, reused signature, or an expired request (→ `expired`).
- Contributes to **AC-11** (all repo gates green).

Provided:

interface PaymentRequestService {

Routes (Q-API-01): `POST /api/gateway_solana/payment-requests` (`{ orderId }` → `{ id, url, qrPayload, reference, amount, mint, decimals, expiresAt }`),
`GET /api/gateway_solana/payment-requests/[id]/status` (→ `{ status, signature?, slot?, explorerUrl? }`; calls `reconcile`),
`GET|POST|OPTIONS /api/gateway_solana/transaction-request/[reference]` (Solana Pay transaction request; `requireAuth: false`; CORS `*`).
Events (Q-TS-05): `gateway_solana.payment.confirmed`, `gateway_solana.payment.failed` (`clientBroadcast: true`), payload `{ paymentRequestId, orderId, reference, signature, slot, amount, mint, status }`.
AI tools (Q-API-04): `solana.create_payment_request` (`isMutation: true`, input `{ orderId }`, requiredFeatures `['gateway_solana.manage']`), `solana.get_payment_status` (`{ paymentRequestId }`).
Memo format (Q-SOL-07): `aegis:v1:pay:<paymentRequestId>`.
Adapter mapping (Q-PAY-07): `createSession` → create request + return url; `getStatus` → `reconcile`; `verifyWebhook` → constant-time compare of `Authorization` with `HELIUS_WEBHOOK_AUTH` + `getTransaction` re-fetch; `capture` → no-op success; `cancel` → set `expired`; `refund` → `{ supported: false, reason: 'MANUAL_REFUND_FROM_TREASURY' }`; `mapStatus` → `pending→pending, confirmed|finalized→paid, partially_paid→partially_paid, expired→cancelled`.

## 7. Step-by-step implementation guide (numbered, each step = one commit)
1. **Package wiring.** Fill `package.json` (name `@open-mercato/gateway-solana`, `peerDependencies` on `@open-mercato/shared`, `@open-mercato/core`; deps: `@solana/web3.js` `1.99.x` exact, `@solana/spl-token` (v1-compatible line), `@solana/pay` `1.0.26` exact, `@solana/kit` only as transitive), `index.ts` re-exporting the module, `acl.ts`, `setup.ts` (`defaultRoleFeatures: { admin: ['gateway_solana.*'], employee: ['gateway_solana.view'] }`), `i18n/en.json`. Run `yarn generate` and `yarn typecheck`.
2. **Entity + migration.** `SolanaPaymentRequest` in `data/entities.ts`, table `gateway_solana_payment_requests`: `id` uuid, `tenant_id`, `organization_id`, `order_id` uuid, `reference` string (base58 pubkey, unique), `recipient` string, `mint` string (`'SOL'` or mint address), `amount` string (bigint base units), `decimals` int, `memo` string, `status` enum (`pending|confirmed|finalized|expired|partially_paid`), `signature` string nullable, `slot` bigint nullable, `paid_amount` string nullable, `expires_at` timestamptz, `created_at`, `updated_at`, `deleted_at`. Zod validators in `data/validators.ts`. `yarn db:generate`, review the migration and snapshot, `yarn db:migrate`.
3. **Integration descriptor.** `integration.ts`: `IntegrationDefinition` with credentials `treasuryAddress` (text, required), `acceptedMints` (json; default `[{"symbol":"USDC","mint":"4zMMC9srt5Ri5X14GAgXhaHii3GnPAEERYPJgZJDncDU","decimals":6},{"symbol":"SOL","mint":"SOL","decimals":9}]`), `requestTtlMinutes` (default 30). Read credentials through `integrationCredentialsService` (see how gateway-stripe does it).
4. **Payment request service + pay URL.** `create()` generates `reference = Keypair.generate().publicKey.toBase58()`, memo `aegis:v1:pay:<id>`, `expires_at = now + ttl`; `pay-url.ts` builds `solana:https://<PUBLIC_BASE_URL>/api/gateway_solana/transaction-request/<reference>` and a QR payload string (use `@solana/pay` `encodeURL` only for the transfer-request fallback URL; keep Kit objects inside this file).
5. **Transaction builder (web3.js 1.99).** `buildTransaction(reference, payer)`: for SPL mint → `getAssociatedTokenAddress` for payer and treasury; if the treasury ATA is missing add `createAssociatedTokenAccountInstruction` (payer pays rent, Q-PAY-04 C as extra); `createTransferCheckedInstruction(payerAta, mint, treasuryAta, payer, amount, decimals)` with the `reference` pubkey appended as `{ pubkey, isSigner: false, isWritable: false }`; memo instruction (`MemoProgram`, `aegis:v1:pay:<id>`) placed **before** the transfer so the transfer is the last instruction (required by `validateTransfer`); for `SOL` → `SystemProgram.transfer` with the same reference key. `feePayer = payer`, `recentBlockhash` from `core.connection().getLatestBlockhash('confirmed')`. Reject if the request is not `pending` or is expired.
6. **Transaction-request route.** `api/transaction-request/[reference]/route.ts`: `OPTIONS` → 204 with CORS headers (`Access-Control-Allow-Origin: *`, `Access-Control-Allow-Methods: GET,POST,PUT,OPTIONS`, `Access-Control-Allow-Headers: Content-Type, Authorization, Content-Encoding, Accept-Encoding, X-Accept-Action-Version, X-Accept-Blockchain-Ids`, `Access-Control-Expose-Headers: X-Action-Version, X-Blockchain-Ids`); `GET` → `{ label: '<tenant name>', icon: '<PUBLIC_BASE_URL>/icons/aegis.png' }`; `POST { account }` → `{ transaction: base64(serialize({ requireAllSignatures: false })), message: 'Pay <amount> <symbol> for order <n>' }`. `metadata = { GET: { requireAuth: false }, POST: { requireAuth: false }, OPTIONS: { requireAuth: false } }`; `openApi` export mandatory.
7. **Reconcile service.** `reconcile(reference, hint)`: load request; if `status in (confirmed, finalized)` return unchanged; if `expires_at < now` and still `pending` → `expired`. Find the signature: `hint.signature` if provided, else `@solana/pay` `findReference(rpcKit, reference, { commitment: 'confirmed' })` on a Kit RPC created from `SOLANA_RPC_URL` inside this file; then `validateTransfer(rpcKit, signature, { recipient: treasury, amount, splToken: mint !== 'SOL' ? mint : undefined, reference })`. On success: assert the signature is not already stored on another request (unique index on `signature`), set `status = confirmed`, `signature`, `slot`, `paid_amount`; emit `gateway_solana.payment.confirmed`; update the `GatewayTransaction` through the hub's service (see gateway-stripe's processor). On `validateTransfer` amount failure where `post − pre > 0` but `< amount` → `partially_paid` with `paid_amount`. Wrong mint / wrong recipient → leave `pending`, emit `gateway_solana.payment.failed` with `reason`. Wrap in a DB transaction; idempotent on `(id, signature)`.
8. **Adapter + DI.** `lib/solana-pay-adapter.ts` implements `GatewayAdapter` per §6 mapping; `di.ts` registers `paymentRequestService`, `reconcileService`, `solanaPayAdapter` (`asFunction(...).scoped()`), calls `registerGatewayAdapter('solana_pay', ...)`, `registerPaymentGatewayDescriptor({ key: 'solana_pay', title: 'Solana Pay (USDC/SOL)', ... })`, `registerWebhookHandler('solana_pay', handler, { queue: 'gateway_solana' })` (handler = constant-time header compare then `reconcile`).
9. **Payment-request routes.** `POST /api/gateway_solana/payment-requests` (`requireFeatures: ['gateway_solana.manage']`), `GET /api/gateway_solana/payment-requests/[id]/status` (`requireFeatures: ['gateway_solana.view']`; returns `explorerUrl = https://explorer.solana.com/tx/<sig>?cluster=devnet`). Both with `openApi`.
10. **Subscriber.** `subscribers/reconcile-on-tx-observed.ts`: `metadata = { event: 'solana_events.tx.observed', persistent: true, id: 'gateway_solana:reconcile-on-tx-observed' }`; if `payload.accounts` contains a `reference` of a `pending` request or `payload.memo` starts with `aegis:v1:pay:` → `reconcile(reference, { signature })`.
11. **AI tools.** `ai-tools.ts` with `defineAiTool` for `solana.create_payment_request` (`isMutation: true`) and `solana.get_payment_status`.
12. **Tests** (see §9), `README.md` (setup, env, how to test with a devnet wallet), `REPORT.md` requests: `modules.ts` entry `{ id: 'gateway_solana', from: '@open-mercato/gateway-solana' }`, currencies `USDC`/`SOL`, `.env.example` keys `TREASURY_WALLET`, `USDC_MINT` already present (confirm).
